Required to save edits directly to the repo from this page. Stored only in this browser's localStorage.

  1. Open github.com/settings/personal-access-tokens → Generate new token → Fine-grained.
  2. Resource owner: jsneij. Repository access: Only select repositories → projectboardgames.
  3. Permissions → Repository → Contents: Read and write AND Actions: Read and write (Actions is needed for the Explorer "Refresh candidates" button to trigger the discovery workflow). Leave everything else off.
  4. Set an expiration (e.g. 90 days), generate, copy the token (starts with github_pat_…).

You can revoke this token any time from the same GitHub page. Click Forget token below to remove it from this browser.
